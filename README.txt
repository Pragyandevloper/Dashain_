# Dashain Greeting Website

A simple responsive HTML/CSS/JavaScript website made by Pragyan.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. Internet is needed for the remote background photo and Google Fonts. The website itself does not need a server.
